# Bonus Karya Asli — Satu Laci Utuh dari Lumbung

Folder ini salinan **plek-ketiplek satu laci belajar** dari basis pengetahuan privat pemiliknya — disalin atas izin pemilik sebagai contoh hidup penerapan bab 04: peta belajar (mol-*), catatan per topik (rag/, ai-tuning/), kamus istilah, dan readme lacinya. Bukan contoh yang dikarang biar rapi — ini barang yang beneran dipakai harian, lengkap dengan status "belum dikerjain"-nya.

**Yang diubah dari aslinya — satu hal, demi segel:** nama produk internal disamarkan jadi "kasir" (nama model, dataset, dan persona di contoh-contoh ai-tuning). Selebihnya utuh, termasuk tanggal, status centang, dan riwayat konvensinya.

Cara baca yang disarankan: mulai dari `readme.md` (peta lacinya), lalu `mol-rag.md` / `mol-ai-tuning.md` (peta belajar per topik), baru selami catatan detailnya.
